تفعيل المزامنة (مرة واحدة بس):
1) ادخل console.firebase.google.com ← Add project (اسم أي حاجة، وممكن تقفل Analytics).
2) Build ← Authentication ← Get started ← Sign-in method ← Google ← Enable ← Save.
   ثم Settings ← Authorized domains ← Add domain ← اكتب دومين موقعك (مثال: username.github.io).
3) Build ← Firestore Database ← Create database ← Production mode ← اختار أقرب منطقة.
   ثم تبويب Rules والصق ده واضغط Publish:
   rules_version='2';
   service cloud.firestore{match /databases/{d}/documents{match /users/{uid}{allow read,write: if request.auth!=null && request.auth.uid==uid;}}}
4) Project settings (⚙️) ← Your apps ← أيقونة الويب </> ← Register app ← انسخ قيم firebaseConfig.
5) افتح firebase-config.js والصق القيم (apiKey و authDomain و projectId و appId) ثم ارفع الملفات على GitHub.
6) افتح الموقع واضغط «☁️ تسجيل الدخول بجوجل» على كل تلفون بنفس الحساب.
