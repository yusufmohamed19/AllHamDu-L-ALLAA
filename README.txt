يومي مع الصلاة - خطوات التشغيل
1) ارفع كل محتويات المجلد (بنفس الهيكل) على استضافة HTTPS مثل Netlify Drop أو GitHub Pages أو Cloudflare Pages.
2) افتح الرابط من الموبايل (Chrome أو Safari): هتظهر رسالة إضافة التطبيق للشاشة.
3) ملاحظة: لازم HTTPS، والتشغيل بالضغط المزدوج على الملف مش هيفعّل التثبيت.

ملاحظة التثبيت: زر «إضافة» بيظهر لما المتصفح يدعم التثبيت (Chrome/Edge على أندرويد)، وبالضغط عليه بيظهر تأكيد النظام وبعدها التطبيق بيتضاف تلقائي.
بعد رفع النسخة الجديدة افتح الموقع مرتين (أو امسح بيانات الموقع) عشان يتحدث الكاش.
